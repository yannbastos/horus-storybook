# Instruções para agentes

Este repositório é o laboratório visual React/Storybook do HORUS. O aplicativo C#/Avalonia está em outro repositório: https://github.com/yannbastos/horus.

Leia [CARTA-AO-CODEX.md](CARTA-AO-CODEX.md) para o planejamento audiovisual sobre Hermes. A próxima entrega é diagnóstico de integração na máquina principal, sem implementar interface ou alterar o motor.

- Leia o README antes de alterar. Mantenha documentação em pt-BR.
- Use tokens de `src/horus/tokens.css`, fontes locais e temas claro/escuro/sistema.
- Preserve acessibilidade, responsividade e `prefers-reduced-motion`.
- Dados e telas são exemplos. Não implemente funcionalidades reais de estudo sem solicitação.
- Não sincronize ou altere o aplicativo C# sem autorização.
- Execute `npm run build`, `npm run lint` e `npm run build-storybook` para validar mudanças.
- Não invente resultados de testes ou verificações visuais.
- Não escolha licença. Preserve as licenças das fontes.
- Não faça commit, push, merge, operações destrutivas ou crie remotos sem autorização.
- Use uma branch por tarefa; tipos em inglês e descrições de branches e commits em português.
- Peça aprovação antes de mudanças significativas de arquitetura, escopo ou dependências.
